# HanziGrammar — Chinese Translation & Grammar Analyzer Web App

เว็บแอปพลิเคชันแปลภาษาจีนและวิเคราะห์ไวยากรณ์เชิงลึกแบบ Interactive พร้อมระบบจับคู่สีและแจกแจงโครงสร้างประโยค

---

## 🌟 ฟีเจอร์เด่น
1. **Interactive Color-Coded Syntax:** ไฮไลต์สีแยกประเภทคำและไวยากรณ์ (ประธาน=ฟ้า, กริยา=เขียว, กรรม=ส้ม, ไวยากรณ์พิเศษ=ม่วง, เวลา/สถานที่=ชมพู, ส่วนเติมเต็ม=เขียวอมฟ้า)
2. **Synchronized Hover:** ชี้เมาส์ที่คำภาษาจีนเพื่อไฮไลต์คำแปลและความหมายในตาราง หรือชี้ที่การ์ดไวยากรณ์เพื่อไฮไลต์กลุ่มคำที่ประกอบเป็นโครงสร้างนั้น
3. **Hybrid Engine (ประหยัดโควตา):**
   - ศัพท์เดี่ยว/วลีสั้น: ค้นหาผ่าน **Local Dictionary** ในเบราว์เซอร์ทันที (0 API Request)
   - ประโยคยาว: ส่งวิเคราะห์ผ่าน **Gemini 1.5 Flash (Free Tier 1,500 ครั้ง/วัน)** ด้วย Structured JSON
4. **Audio & Pinyin Toggle:** ปุ่มเปิด-ปิดพินอินด้านบนตัวอักษรจีน (Ruby tag) และปุ่มกดฟังเสียงอ่านภาษาจีนผ่าน Web Speech API
5. **History & Export:** แคชประวัติการวิเคราะห์ในเครื่อง และปุ่มส่งออกข้อมูลเป็น Markdown / Anki Flashcard

---

## 🚀 วิธีเปิดใช้งาน
1. เปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ (Chrome, Edge, Safari, Firefox)
2. กดไอคอน ⚙️ ด้านขวาบนเพื่อใส่ Gemini API Key (รับฟรีได้ที่ [Google AI Studio](https://aistudio.google.com/))
3. พิมพ์ข้อความภาษาจีนแล้วกด **"วิเคราะห์ประโยค"** ได้ทันที
