# 05 — Hanzi Stroke Order Modal & Web Speech Speed Controller

**What to build:**
Character anatomy modal powered by `hanzi-writer` that shows animated stroke order, stroke count, radicals, and stroke practice mode when clicking any Chinese character. Audio player with Web Speech API (`zh-CN`) supporting playback speed adjustment (0.75x, 1.0x, 1.25x).

**Blocked by:**
02 — Char-by-Char Ruby Annotation & Color-Coded Syntax Roles

**Status:**
ready-for-agent

## Acceptance Criteria
- [ ] Clicking any Hanzi opens modal with animated stroke order and radical breakdown.
- [ ] Modal includes "Play Animation" and "Practice" interactive canvas.
- [ ] Audio button plays pronunciation with user-selected speed (0.75x, 1.0x, 1.25x).
