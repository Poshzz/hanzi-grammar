📖 จุดไวยากรณ์สำคัญในประโยค (Grammar Points)

📝 คำแปลและหน้าที่ของคำรายคำ (Lexical Table)

คำศัพท์ พินอิน ชนิดคำ หน้าที่ ความหมายในบริบท ระดับ เสียง

🕒 ประวัติการวิเคราะห์ บันทึกอัตโนมัติ

💡 เคล็ดลับการใช้งาน

  • Hover บนคำ: ชี้เมาส์ที่ตัวอักษรจีนเพื่อดูความเชื่อมโยงกับคำแปลและตาราง
  • Hover บนการ์ดไวยากรณ์: ชี้เมาส์ที่การ์ดไวยากรณ์เพื่อไฮไลต์กลุ่มคำที่ประกอบเป็นโครงสร้างนั้น
  • คลิกที่คำ: กดที่ตัวอักษรจีนเพื่อฟังเสียงอ่านออกเสียงมาตรฐาน
  • โหมดประหยัดโควตา: คำศัพท์สั้นๆ จะถูกค้นผ่าน Local Dictionary ในเครื่องทันที (0 API Request)
